## How to Take Full-Page Screenshots

**Chrome (recommended):**
1. Open the page
2. Press `F12` to open DevTools
3. Press `Ctrl+Shift+P`
4. Type "screenshot"
5. Select "Capture full size screenshot"
6. PNG saves automatically to Downloads

**Windows Snip & Sketch:**
- `Win + Shift + S` → drag to select area
