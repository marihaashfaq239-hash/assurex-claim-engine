SRS §1.2 — Complete 15-Step Claim Flow

From registration to decision.

01
User Registration
Email-based auth, 4 roles assigned, role-based dashboard on login.
02
Product Registration
Brand, model, serial, purchase date, warranty duration. Auto warranty record.
03
Warranty Record
Start/expiry dates, coverage, exclusions. Status: Active/Expiring/Expired.
04
Claim Creation
Fault description, damage type, fault date, repair history. CLM-0000001.
05
Document Upload & OCR
Tesseract + EasyOCR: invoice, serial, purchase date, amount, retailer.
06
Data Validation
Mandatory fields, file types, 23-point contradiction detection, missing docs.
07
Pre-Processing
19 features: product_age, warranty_days, has_receipt, serial_match, etc.
08
Python ML Model
Random Forest 98.22%. OneHotEncoder + StandardScaler + RFC(200). 3-class scores.
09
Claim Summary Card
600×420px PNG by Pillow. Product age, warranty, fault type. No prediction on card.
10
GTM Image Model
99.11%. Gradient Boosting on 278 image features. 3-class confidence scores.
11
Model Comparison
Diff=|Python%−GTM%|. 5 tiers: Strong(≤5%), Acceptable, Weak, Uncertain, Disagree.
12
Rule Engine
11 JSON rules: warranty_active, claim_period, purchase_proof, serial_match...
13
Final Decision
Likely Valid · Likely Invalid · Manual Review. Model agreement + rules + docs.
14
Manual Review
Reviewer: full AI scores, OCR, rules. Approve / Reject / Override with reason.
15
Status & Notify
8 stages: Draft→Submitted→Evaluation→Manual→Info→Approved/Rejected→Closed.
